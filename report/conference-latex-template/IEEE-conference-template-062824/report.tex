\section{Introduction}
General detection of arbitrary objects is a fundamental problem in computer vision. While the performance of object detection models has improved significantly in recent years, conventional models are limited to detecting a pre-defined set of object categories that they have been trained to recognize. This limits their use to specific applications where the set of objects of interest is known in advance. \cite{liu2019} \cite{Edozie2025}

Open-vocabulary detection (OVD) attempts to address this limitation by utilizing large-scale vision-language models (VLMs) to enable the detection of objects not based on a pre-defined set of classes, but their textual descriptions. This allows for a potentially unlimited number of object categories to be detected, including fine-grained categories that may not be well-represented in existing datasets. In this paper, we investigate the performance of state-of-the-art OVD models and VLMs on the task of fine-grained object detection for augmented reality (AR) applications in the context of guided repairs. We evaluate the models on a custom dataset of images of various objects commonly found in AR repair scenarios, and analyze their performance in terms of detection accuracy and generalization to unseen object categories.
